# Changelog

`@quillmark/collab`. An entry is written into `## Unreleased` by the change that earns it; a release promotes that body to its own version section.

## Unreleased

**Live editing of one document by several clients.** `bindDocument` keeps a WASM `Document` equal to a shared Yjs state in both directions: every body and `richtext` field as text with its lines, containers, marks and islands, every `text` field as plain text, every other field as a value, and the card list, kinds and titles. `push(op)` writes a local commit; `onRemote` says what a remote one moved, with the text delta a host maps its caret through. `seedDocument` writes the update a session starts from, the same bytes on every client. `joinSession` runs a session over a `SessionLog`: the session opens with its seed in one write, every local update is appended, every other client's is applied, each save carries the Y snapshot it reflects so a stale save is refused and a deletion is saved, and a session nobody is in ends once saved so the next join starts afresh from the save. `localLog` is a `SessionLog` in `localStorage`, for every tab of one origin.

**Writes from a revision.** `writeFrom` makes an edit on the state a slow writer read and returns it as an update that merges with whatever was written since, with the changes it made and the conflicts it meets; `changesSince` reads what moved between two states, cards matched by identity. `session.revision()` names the state a writer reads, and `session.apply(update, writer)` applies such an edit under its writer and returns an undo manager for it. `readLog` and `writeLog` do the same through a `SessionLog` with no session joined, the write appended and saved. `SessionLog.append` takes the writer an entry is by, and `joinSession` takes the session's own.
