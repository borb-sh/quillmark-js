# Changelog

`@quillmark/collab`. An entry is written into `## Unreleased` by the change that earns it; a release promotes that body to its own version section.

## Unreleased

**Live editing of one document by several clients.** `bindDocument` keeps a WASM `Document` equal to a shared Yjs state in both directions: every body and `richtext` field as text with its lines, containers, marks and islands, every `text` field as plain text, every other field as a value, and the card list, kinds and titles. `push(op)` writes a local commit; `onRemote` says what a remote one moved, with the text delta a host maps its caret through. `seedDocument` writes the update a session starts from, the same bytes on every client. `joinSession` runs a session over a `SessionLog`: the session opens with its seed and quill version in one write, every local update is appended, batched while an append is out and retried when one fails, every other client's is applied, each save carries the Y snapshot it reflects so a stale save is refused and a deletion is saved, a client holding a value its Document refused does not save, and a session nobody is in ends once saved so the next join starts afresh from the save. `localLog` is a `SessionLog` in `localStorage`, for every tab of one origin.

**Writes from a revision.** `writeFrom` makes an edit on the state a slow writer read and returns it as an update that merges with whatever was written since, written and compared by line, with the changes it made and the conflicts it meets; an edit the update cannot carry whole is refused with `Unwritable`. `changesSince` reads what moved between two states, cards matched by identity and text as hunks. An edit names any number of card operations, and `cardOps` derives them from a `reviseDocument` receipt's `from`, moving exactly the cards `changesSince` reads as moved. `session.snapshot()` names the state a writer reads, and `session.apply(update, writer)` applies such an edit under its writer. `readLog` and `writeLog` do the same through a `SessionLog` with no session joined, naming a state by a short `Revision`, `{ epoch, count, check }`, whose check refuses a count the writer did not read: the read changes nothing, and the write appends only while the log holds what its conflict check saw, once per `key`, ending a session nobody is in and opening one only when it has an edit to append. `SessionLog.append` takes the writer, the expected entry count and a key, and answers how it went; `since` reports the entry count, and `upTo` returns the first entries. `joinSession` takes the session's own writer.
