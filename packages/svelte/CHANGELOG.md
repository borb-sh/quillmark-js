## Unreleased

## v0.11.0 - 2026-09-16

**The `@quillmark/wasm` peer floor is `>=0.113.0-0`, where the five content vocabularies close.** A line `kind`, a container, a mark `type`, an island `type` and an island's `loss` admit their built-ins and nothing else: a name outside one is refused wherever content is decoded, and a stored row carrying one stops opening. No first-party writer ever produced another name, so the rows this reaches are the ones a host authored one into through `overwrite`, `applyChange` or a card body — find and respell them while a 0.112 build can still open them. What this package sheds with the open sets is the tier that carried them across an edit: the inert `unknown` mark, the paragraph's `unknown` line-kind attribute and the `unknown_container` node leave the PM schema, with the `data-qm-unknown-*` names they crossed the clipboard under. An island type the content model does not name is not an island on a paste either, and a `loss` outside its set reads as the weakest class. A body copied from a page still running a carrier pastes as its text, which is what a paste rule keeps of markup it does not know.

**Shift-Enter opens a line break in a body.** The `hard_break` was the whole way through the codec with no key that minted it — the gesture reached the shape only through the browser's own `<br>`, which this schema's `parseDOM` happens to read back, so what a press did was the host's to decide. It is a link of the body's chain now: inside a fence it is the newline Enter takes, the same command under both keys, and in a heading, or over any selection that is not a text range, the key is claimed and does nothing, declining being what hands it to the browser. The break carries no marks, matching what `decode` mints, and the caret keeps them, so a bold run reads across the line it wrapped at. The two surfaces that are one line by construction claim it beside the Enter each already owns: a `richtext(inline)` leaf and a table cell.

**A `hard_break` is not a thing a heading holds.** A heading is a block of one line — the store clears a continuation after one, and markdown has no syntax for a break inside a heading — so the schema declares the node out of it and every door inherits the rule: a `<br>` inside an `<h1>` parses away, retyping a broken paragraph to a heading drops the break, and a `\n` joined into a heading becomes the space the leaf's own DOM was already drawing. A paragraph is unchanged.

**A container's zero `instance` is absent, not spelled.** Canonical content has one byte form, so a read omits the key where the value is the zero it defaults to, and a host reading `container.instance` off a `Content` finds `undefined` where it found `0`. Absent and `0` mean one thing at every reader: this package's projection omits the key too, which is what keeps a list or a quote edit from reading as a line-metadata change on every keystroke.

**A url reaching the model from outside it is stored percent-encoded.** CommonMark admits no line ending in a link destination, so the authored lane refuses one at `MarkOp.add`, at an `image` island op and at `overwrite` alike — and a leaf whose two commit lanes both throw stops persisting for the session, since the PM doc still holds the mark on the next keystroke. A `\r` or `\n` in a pasted `href`, in a pasted image island's `url` and in the link prompt's own value becomes `%0D` / `%0A`, which is what `toMarkdown` writes for one anyway. A url carrying neither is untouched.

**`PreviewStrings` loses `unsupported`.** Canvas paint is no longer a capability a backend has or lacks: every backend paints, the boundary's `Engine.supportsCanvas` and `LiveSession.supportsCanvas` are gone, and a counted page is the whole condition — `paint` and `pageSize` refuse only a page the count excludes. The message states are `renderFailed` and `noPages`; a consumer wording `unsupported` is passing a key the type no longer declares, for a state nothing reaches. A raster the backend cannot allocate is refused rather than attempted, so a `setDensityZoom` of zero, a negative or a non-finite number now surfaces `renderFailed` where it drew a blank page.

**Every member of the content vocabulary spells its payload in `attrs`.** A built-in put its payload in named siblings and an unknown in one opaque bag, so which spelling a document used depended on whether the build that wrote it knew the name. One bag: `heading`'s `level`, `code`'s `lang`, a `link`'s `url`, an `anchor`'s `id` and a `list_item`'s `ordered`/`start`/`ordinal` all read one level down, with the envelope keys (`kind`/`type`/`container`, `containers`, `continues`, `start`/`end`, `instance`) left as siblings. Nothing a host holds moves: stored documents need no migration, the decoder reading the sibling spelling wherever the bag is absent, and this package's whole surface — the leaf, the mark ops it lowers, the anchors it hands back — takes and returns what it did. A host reading a `Content` off `getContent` reads its payloads under `attrs`, and the authored lane throws on the sibling spelling rather than landing it somewhere it did not aim. The mark diff drops the case it kept for links: coverage sets key on the `(type, attrs)` pair the wire carries, which is the seam's own tie-break.

**`mapMarks` answers where a bundle leaves a field's marks.** Every text-moving channel of a `ChangeBundle` rebases the marks already in the field by one assoc rule, and the mark diff needed that answer to decide which `markOps` to emit — so it carried a copy of the rule, and the copy drifted. It asks now: `mapMarks(oldRt, bundle)` names the marks the field will hold, `markOps` are the difference from that, and the pre-edit anchor set is read off the same answer rather than passed in beside it. The rebase is the store's to define at every position, including an insertion at a zero-width mark, which is where the copy was wrong.

**An anchor inside a table cell holds its position against text typed at it.** A cell edit rebased its held anchors a character to the right where the same gesture in a field left them put, so which side of your own typing a comment thread landed on depended on whether it sat in a table. Both lanes take the store's rule now.

**A held `scrollToField` survives the recompile it was held over.** A hop asked while the pane had no box is replayed once it has one, and a page-count change rebuilds the bridge that was holding it — so a caller told the hop had landed watched it be dropped. The held trip is the controller's now and threaded into the bridge, which is what makes a rebuild inherit it.

**A click two pixels off the ink lands.** A glyph's hit box is its line's ink by that glyph's own advance, so the boxes along a line abut and the leading between two lines is inside the paragraph and on no glyph: the reference quill's body sets 9.3pt of ink on a 16.1pt pitch, and the rest of that column answered a click with nothing the reader could see the reason for. Both point queries take a tolerance at the pin and answer with the nearest ink inside it. It is the pointer's imprecision rather than the document's, so it is a fixed size on the screen converted per click at the scale the slot is drawn at — the same two pixels are 3.1pt at the split's own threshold and 1.5pt on a pane twice that wide, a narrow pane being where a line is hardest to hit. What stays dead is whatever a wide pane leaves of the leading, and the whole of a line past its last glyph, both being a line box's to close.

**`VisualStrings` gains `bodyLabel`.** The card body's accessible name reads off the strings, as every other name in this layer does. `VisualStringsInput` is a partial over the defaults, so a host adding nothing is unaffected and one translating the surface has a key to translate.

**A leaf ghosts the default its field declares.** `ProseField` takes a placeholder that nothing passed it, so a body's default text ghosted on every leaf but a richtext or plaintext one, and a date property inside an object dropped its ghosted default where its sibling scalar kinds kept theirs. `ObjectField`'s keyboard landing skips the label row, which took focus to the hint button ahead of the control it describes wherever the property carried a description.

**A `plaintext` field declared `inline: true` mounts as the one-line leaf it asked for.** The boundary served `inline` for richtext alone and now serves it at every type, so such a field takes the inline leaf and `packable` accepts the `ui.compact` beside it: a field that spanned its row packs into a cell wherever its neighbours pack too. Nothing in this package changed to meet it — it reads `inline` off the schema and always did — but a host laying out a quill that declares the pair sees the rows it declared.

## v0.10.1 - 2026-08-26

**The editor takes the width its host gives it, and asks for no more.** A table island scrolls its own columns and caps at the leaf, but a percentage cap is no cap while an ancestor is being sized to what it holds — so the table's full width travelled out of the leaf, out of the card and out of the surface. A host standing the mount in a column that floors at its content (a flex or grid track with no minimum of its own) widened by the whole table, and the pane beside it left the screen. The surface contains its inline size, so nothing a leaf holds reaches past the mount; the island contains its own, so the cap it draws is true wherever it lands. Neither box moves: a narrow table shrinks to its columns and a wide one scrolls inside the leaf. [THEMING](THEMING.md) §"Drop it in" states the guarantee where a host laying its own tracks reads it, and the preset's hosts, flooring nothing at their content, never saw the fault.

## v0.10.0 - 2026-08-26

**The `@quillmark/wasm` peer floor is `>=0.110.0-0`, where the seam spells every container's `instance`.** The discriminator that tells one container from an adjacent sibling of identical shape was a writer's obligation no checker asked for; it is required on `ContentContainer`, `ContentContainerInput` is gone, and `LineOp.setContainers` takes the one shape. The projection spells the field on every container it mints rather than only where it is non-zero, which is what the read type now asks for and what the store already canonicalized to; the fold reads it where it stood. Nothing about which runs weld moves: what a writer put side by side still survives the commit, and what the store holds still comes back as two.

**A document that renders validates.** `validate` conforms each value at the render floor's leniency before judging it, so a fatal `validation::*` means the document does not render. Two things move for a host reading the codes under a field: a value the floor adopts — a bare scalar where an `array` is declared, `"3"` for an `integer` — raises nothing where it raised `validation::type_mismatch`, and a bare scalar the floor stringifies into an `enum` field is domain-checked on that string, so a spelling outside `values:` raises `validation::enum_violation` where it was silent. One refused element no longer mistypes its siblings: judging runs per node, so `[true, "abc"]` under `integer` items is one mismatch, at index 1. `formatDiagnostic` words the same three validation codes.

**The slash menu offers no divider.** A rule holds no content, so the row was reachable only from an empty block — where it landed a construct the caret then had to step past, in a menu whose every other name fills the block the writer is already in. `---` at the head of a block is the door it keeps (`codec/inputrules.ts`), and it draws what it mints.

**A preview click into an array element washes that row, and not the list around it.** The arrival wash answers "here" for a click made in the other pane, and a landing on `main.keywords[0]` bloomed every row the field holds — the field, where the click had named one row. The element lane hands the row it took back with the landing, so the wash carries the address's own granularity; an `object[]` row is washed whole, head and open subform together, being what the address named. A landing on the field itself, and one naming a row the document has since dropped, wash the list as before.

## v0.9.0 - 2026-08-24

**The `@quillmark/wasm` peer floor is `>=0.109.0-0`, where two adjacent containers of one shape are two.** Container identity is the container path plus contiguity, and the path carried nothing to tell one instance of a shape from the next: `[Quote], [Quote]` read as a single two-paragraph quote, and two one-item lists as a single item whose second line came back an unnumbered continuation. `ContentContainer.instance` is the discriminator, and the codec owes both halves of it. The projection mints one, alternating against the sibling before it, so what a writer put side by side survives the commit; the fold keys on it, so what the store holds comes back as two. The boundary was an ordinal reset and is not: a run's `ordinal`s canonicalize gapless from 0, which is what restarts the second run's numbering once `instance` marks where it begins. The preview reads the same fact from the other side — two adjacent runs typeset as two, and a container inside a list item stops ending that list, so an item's quote or fence stays the item's.

## v0.8.0 - 2026-08-21

**The `@quillmark/wasm` peer floor is `>=0.108.3-0`, where a paragraph holding one bare Typst line marker renders.** `/`, `-`, `+`, `=` and `N.` fire on a space after them or on the line ending there, and the emitter's line-anchor guard tested only for the space — so the `/` that opens the slash menu reached the compile as a term list whose colon is missing, and the preview drew `expected colon` on that keystroke and cleared it on the next character typed. The codec was encoding the paragraph the writer typed and the engine was rendering what it was handed; the escape is the emitter's, and this tier owed the floor. Two more come with it. Text directly after inline code, bold or an image renders when it opens with `(` or `.name`, where Typst read it as arguments to the emitter's own `#raw(…)`/`#strong[…]`/`#image(…)`. And an empty mapping emits `key: {}` at every depth, so an emptied `$ext` namespace no longer leaves a bare `$ext:` that reads back as null — `patchEditorExt` removes a namespace it empties on its own account, not to stay out of that.

**A table draws one control at a time, and it is the one the pointer is on.** The band came up muted under a pointer anywhere on the island, so every grip and both add bars stood to answer a question the pointer had picked out none of. A grip or an add bar is drawn while the pointer is on that control, while a bar holds the focus, or while it is what a gesture is about — the selected line's grip, the lifted one; their boxes meet at no point, so what stands is the one line the pointer has picked out. What it costs is the band's own announcement: an add bar is found by reaching an edge rather than by hovering the middle. Every target is where it was, an invisible button being hit-tested like any other, so what changes is what a table looks like under a passing pointer rather than what it answers to.

**A section heading rides its vertical, one nesting step out from the fields it holds.** The chevron opening a heading stood on the column its fields start on, so the row that names a section began where the section's contents began and nothing in the figure said which held which. It opens at `--_qm-space` instead, the rung the header's own block padding already stands at — the whole air a heading keeps under the payload's top rule, which a rule cannot inset past, so it is the only inline inset that squares that corner.

**A payload rule is drawn on the edge of the box it faces, and the air is that box's own**, so each rule stands off the ink beside it by the inset that squares its corner: `--_qm-nest` for a field row, `--_qm-space` for a heading, each the rung that ink already stands off a vertical inline. Two headings closing the payload's two ends now stand the same distance off their rules, where the lower one stood three rungs against the upper one's one. Where the last section is open the box carries the longer rung as real padding, so its vertical ends on the rule at every frame of a fold rather than only at the two ends of one; where a reveal moved the accordion instead, nothing about it animates, the landing measuring its target one flush after asking.

**A card's edge stands a step tighter than the verticals inside it**, `--_qm-space-2` where they keep `--_qm-nest`: an edge that closes a block nests nothing under it, and the two rules it holds run that much further for the room. Everything the card draws moves with it, so what a field row or a heading keeps from the rules and the verticals beside it is unchanged. What a field row keeps from a rule is the rung of whichever stroke holds it — the card's own edge for the ungrouped block, the nesting rung for a section's fields — so the corner it closes reads square at either.

**The verticals carry half a step more width than the strokes that close a block or rank two**, `--_qm-vertical-width` at 1.5px against the hairline everything else reads: a section's, a subform's and a blockquote's alike. Depth is what a vertical states and the one thing a dense card asks a reader to find, where an edge that closes and a rule that ranks are read from the block they bound.

**A headerless card keeps a rung of its own above its payload** rather than standing as the rule its first section's vertical would run to. The tangent corner costs more than it pays there: a card opening on air reads as an island, and one whose first heading tucks under its own edge reads as a lid.

**A field row stands the longer rung off whatever follows it**, the next section's heading as well as the rule closing the payload. An open section's vertical caps in air rather than in margin handed straight back, so the boundary under it is `--_qm-nest` where it was two thirds of one, and a field row ends the same distance from the heading below it as from a rule or the card's own edge.

**A headerless card's edge is the stroke its payload's first section faces**, where nothing stands between the two. The card insets nothing there and the box facing it carries the rung, the way a payload rule's does: a heading tucks under the edge at `--_qm-space` with its vertical running to it, and a field row stands the whole `--_qm-nest` below rather than that and the section's own cap besides. A card that opens on its body keeps the inset, prose being neither.

**A disclosure row stands off the next by the two headers' own block padding and nothing else.** The accordion spent a rung of gap between its sections besides, calibrated as the distance the fields keep between their rows — a label over a well, which reads as a float between two lines of text — so a run of shut headings read as separate items rather than as the list of sections it is. The rows tile now, and their tap targets with them. A section's vertical caps its free end at `--_qm-space`, the rung a subform's own vertical already caps at, so the stroke ends where it did against the heading below it and the two figures cap alike.

## v0.7.0 - 2026-08-19

**A discrete hop outranks the follow.** `scrollToField` ends the follow it displaces, so a hop taken while a follow is live is no longer re-centred away at the next `refresh` — the hop has just moved the caret off screen, which is where the guard cannot save it. A hop that placed nothing moved nothing and takes no rank.

**The fold's clearance is bounded at both ends.** What a target keeps clear of each edge was its own height and nothing else, so a centred target needed a port three times its height to ever pass: a tall located rect or a short split track was re-centred by every keystroke, and a zero-height rect collapsed the term to bare intersection, scoring a caret flush against an edge as clear. The clearance is floored at a caret's height and capped at a third of the room the port has to spare, and a target taller than the port is clear while it covers the port — no scroll shows more of it. `clearOfTheFold` reads two vertical spans, so its arithmetic is driven directly rather than through layout.

**A preview pane with no box holds its trip rather than answering from one.** A pane the shell has hidden reports a 0×0 box, which is a pane with no answer and not a fold to be clear of: both trips are held there, and the last one held runs when the container has a box again, which its own `ResizeObserver` reports. The same transition no longer rasters — a 0-width tick holds the last real width instead of repainting every mounted page at the 1× raster.

**A caret walked into a table cell takes the scroller with it.** Every route into a cell lands through `focusCell`, which dispatches flagged and on the leaf's own line box. ProseMirror focuses with `preventScroll`, so a Tab past the right edge of a wide table typed where the scroller had not moved.

**A menu takes the root it portals into as its collision boundary.** The slash menu stops flipping into room the pane clips, and its highlight scroll stops reaching the pane the anchor is measured in; the kind menu and the enum listbox take theirs for the same reason.

**The card stack's post-mutation scroll waits out the reorder trip** that holds the slot at its pre-move position, and coalesces on a ticket rather than a pending id: an insert and a move of one card inside one tick served the insert's `center` where the move asked for `nearest`.

**The workspace states its one column.** An implicit grid track is `auto`, and a `.qm-split` under one contributes its items' max-content through its `fr` tracks, so the shell took the width of the widest surface mounted in it rather than the viewport's — every band that wide, and the second pane past the edge. A host holding its content to a maximum never saw it; one spending the whole screen sees it on the first surface it mounts.

**A press on a section header keeps that header in the fold.** Closing one section as another opens moves every box under the one it closed — including, where a long section stands above a short one, the header just pressed, carried off the top of the fold and out from under the pointer still resting on it. The press now takes the trip every landing here takes, the minimum to the nearest edge: a header the collapse never carries out of view costs no scroll, and one it would rides up and parks at the fold's edge with the section it opened unfolding into the screen below. Both panels keep their animation, the trip being taken per frame over the motion rung rather than computed once. The platform answers none of it: scroll anchoring picks its anchor off the layout, and what fills the viewport as a section collapses is that section's own content, whose top never moves. An array's object rows take the same hold, one open row at a time being the same shape one rung in.

**Nesting in the editor is a ladder of verticals, not a rule across the block.** The metadata bracket's top rule is gone and the subform's band with it; the rule closing the payload stays, that being the one boundary a horizontal is right for — it ranks a card's fields against its body rather than saying what sits inside what. What states depth now is one stroke at up to three positions: the card's own edge, an open section's vertical one rung in, and a subform's one rung further, each standing its content off itself by that same rung — so how deep a field sits is a distance repeated rather than a line to be ranked against. A rule across a block says these fields are one thing and what follows is another, which is what a card's body needed said and never what a nested property did; the rung is `--_qm-nest`, and the card's inline inset is the first step of it.

Every accent caps at `--_qm-space` on both ends, so a vertical stands clear of its first label and its last control by the same distance rather than hanging crooked; an open section's two ends are that one rung stated by the two boxes that own those edges — its header's padding above, its panel's below. And where two sections meet the distance is three of that rung — a cap, the gap, a cap — the same whether either side is an accordion group or the ungrouped block, which is the rung the fields inside a section already keep between their rows.

An accordion group draws the vertical open and a subform draws it wherever it mounts, while fields declaring no `ui.group` draw none and stay on the card's own column — a stroke marks a block a reader can name, and the ungrouped ones are the card's own at the rank its body is at. The `edges` distinction a subform took — a band at field level, a closing rule under a control — chose between horizontals and retires with them. A subform's cells no longer share column edges with the fields above them — the inset is the nesting — and still step with them, `--cols` inheriting as before.

## v0.6.0 - 2026-08-18

**The slash menu carries the block shapes.** `heading`, `list`, `numbered-list`, `quote`, `code` and `divider` join `table`, which is what the menu was. The one-door rule they displace was about a construct having two implementations, and these have one: every block shorthand and every pick now runs the same command (`codec/blocks.ts`), a shorthand under a regexp and a pick under a name. So the second door costs a row, and a writer who has never typed `## ` has a route to a heading, a list, a quote, a rule and a code block — which, with no toolbar and a format popover that carries marks over a non-empty selection only, they had nowhere.

A shorthand is anchored to the head of a textblock, so a pick does what the shorthand would have done there, the trigger run consumed first, and **a name is offered only where its command would run** — the menu asks each command rather than restating its guards. The lists are absent at an item's head, where `- ` declines and Tab owns the nesting; the divider off a block with text in it, holding no content to retype into; and a caret mid-paragraph is offered the island alone, which inserts a block after it where the rest turn the one the caret is in. `heading` is level 1, the level `# ` counts to.

The query completes on a prefix of the name **or of any of its words**, so `/list` offers both lists. Over one command a prefix decided nothing; over a two-word name it decides whether the noun a writer has reaches the row at all. The vocabulary's order survives every keystroke, as before.

**The `@quillmark/wasm` peer floor is `>=0.108.0-0`, where a schema address takes every step the schema admits and a container carries ink of its own.** A plate reading a property of a declared container regions on the property (`main.contact.email` where it regioned as `main.contact`), a typed table's row cell on the cell (`main.refs[0].org` where it regioned as `main.refs`), and a whole-array read or a single-assignment `let` alias mints an address that minted none at all. **An address's boxes are now `fieldBoxes`'s union, else every `regions()` rect at or under it**: the descendant rung was a fallback, and an array carrying a region of its own carries it for the ink the plate composes _around_ its rows — the separator between them, a heading over them — so a scroll that took the rung alone landed on that separator and now takes the rows with it. `elementAddrForFieldPath` takes an index terminal only, so a property path declines there and lands its field through `nearestAddrForFieldPath`, which is the address a commit can name. `fieldAt` may name a container where `positionAt` names the element inside it, at the edge the two placements share; the click ladder reads `positionAt` first, so what a click lands on is unchanged.

**An `enum` declaring `variants:` draws the world it selects.** The field rests as a container, `{value: <member>, …that member's fields}`, and draws as the discriminant's select with that member's cells beneath it — the object subform, unchanged, over the same container the field commits by value. The cells a world brings into play appear and retire with the pick, so the schema's one cross-field shape reaches the surface as the thing it means: a cell with no `default:` reads _required in this world_, obliged on the document that selected it and silent on every other.

The drawn world is the one the document renders as: the authored discriminant, or the ghosted `default:`'s member while unset — a defaulted world whose cells were hidden would print answers the form never asked for. A flip keeps the other worlds' answers and so does clearing, which takes the discriminant cell alone; the boundary carries a stranded answer and warns rather than dropping it, so flipping to compare and flipping back costs nothing. A container left holding nothing is an unset field and removes. A stranded answer is held but undrawn: `validation::out_of_variant` is a warning, and the inline lane carries errors only.

**An obliged property carries the required `*` inside a subform.** `validate` anchors obligation per leaf, so a cell inside an object is obliged in its own right and warns as one; the label said nothing, and now states the same axis the field label does. Decorative at that rung — a property label names nothing, so the word rides the control's own accessible name.

**The required `*` is `default:`'s absence and nothing else.** `must_fill:` is retired upstream — declaring it is a load error, and `QuillFieldSchema` no longer carries the key — so the two axes the label used to read collapse to one: a field ghosts a default or asks for an answer, never both. A typed dictionary is exempt at its own rung, a namespace declaring no `default:` at all: reading one off the container would mark every subform required, and the obligation is the leaves' anyway, where the subform's own labels already state it.

**A container's provenance is its cells'.** An absent container descends rather than terminating, so a property's `default:` is reached whether or not anything above it is authored, and `resolve` reports the strongest rung that contributed — `authored` where the document wrote any of it, else `default` where a cell below resolved to one, else the floor. The ghost channel is unmoved: an object-shaped value renders no placeholder at any rung, so what moves is the provenance a host reads off `resolve`.

**No markdown or HTML crosses the clipboard.** The table island's clipboard door is gone in both directions. A `<table>` pasted into a body or into a cell no longer becomes an island: what a paste gets is ProseMirror's own DOM parse against the schema, which for a table is its cells' text. `Mod-C` and `Mod-X` over a held rectangle no longer write one, a grip selection having no copy of its own. Markdown reaches a field by import — Quillmark's conversion to a DTO, or the source editor — which is a whole document with its anchors rather than a fragment that has to be rebased onto one. What ProseMirror does itself is untouched: a paste still carries lists, headings and marks, and `Mod-C` over a selected island still takes the island.

**A preview click on an array element lands the caret it resolved.** The compile answers an element at full precision — `main.keywords[0]` at a cluster-exact USV offset, `plaintext` rows included, both riding the same lowering — and the landing dropped it: the element lane carried a focus and no place, so the row was right and the caret was a guess, at 0 in a `richtext[]` row. `FieldControl.focusElement(index, pos?)` carries the offset down, and `ProseArrayElement.setCaret` spends it the way a `createField` leaf does, over the view the row owns. Nothing reported an error before, which is the shape of the defect: the landing resolved, so there was nothing to report.

What a place means stays the row control's. A JSON `object[]` row takes the bare focus it took before, an offset being a position in rendered content that a textarea has no coordinate to spend. An absent `pos` is the placement rung on this lane exactly as on `Landing`, so a `'segment'` hit lands the row and places nothing; an offset past the row's current value clamps to its end, and an index past the live list still falls back to the field's own landing.

**An error anchored deeper than a commit address draws at the nearest field that holds it.** `validate` walks into object properties and array elements and anchors per leaf, so a coercion failure inside a subform arrives as `main.contact.listed` and one inside a repeater as `main.revisions[0].pages` — paths `Addr` cannot name. Routing dropped them by shape, which since the inline lane went errors-only was the only thing standing between such an error and the user: a document loaded with a bad nested value drew nothing anywhere. Each now routes to the field it hangs off, which is the field whose subform or repeater draws that leaf, and the message names the leaf. Only a path with no addressable prefix drops, which is a config-space or malformed anchor and never a document one. A commit made from the surface is unaffected: an object and an array both commit whole at their field, so a refusal was always keyed at the call site.
