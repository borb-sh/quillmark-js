# Document Model: Boundary Ledger

> **Implementation**: `@quillmark/wasm` (the consumed surface, imported from the peer directly) · `src/lib/core/` (what the package adds at the seam)

## TL;DR

**Not** a document-model design: the `Document`, its mutators, the WASM boundary, and diagnostics are quillmark's, each with a canonical home in quillmark canon. This ledger pins the *exact* quillmark surface `@quillmark/svelte` V1 consumes, cites where each is documented, and marks its stability. It is the one place the version coupling to `@quillmark/wasm` is recorded; when a surface below moves, the editor's dependency moves with it. Nothing re-exports this surface: package code and consumers alike import it from the peer dependency, the single source of truth, and `/core` carries only what the package itself declares over it (the address vocabulary, the error channel, `init`).

**V1 builds on `@quillmark/wasm` 0.116.0**, past the 1.0 API freeze. Every verb in the table below is stable at that pin. The settled ground it stands on: the init gate as the only door to the classes, so the precondition is structural rather than a convention a call site has to know; `store*` verbs for verbatim writes, one unified `Addr` (`{card?, field?}`), the schema-bound `writer`/`reader` doors (`quill.writer(doc)` / `quill.reader(doc)`), a card-first `insertCard(card, at?)`, the quill-free transport read `getStored` (distinct from `reader.get` and `reader.getContent`), the `reader.resolve()` value view, `code`-bearing mutator diagnostics, the canonized anchor-id policy (caller-supplied, unique, invariant) that lets the editor mint anchors at a selection ([CODEC.md](CODEC.md) §Marks), and the `islandOps` channel that puts an island's payload within reach of `applyChange`.

**A content field has one rest form per codec, and one read that spans them.** `richtext` rests as the content object, `plaintext` as its literal string, and a document that came through the transport door rests as authored until `quill.parse` / `quill.conform` lands it. `reader.getContent(addr)` decodes through the codec the declared type names, so the storage form stops being a consumer's business: it is the prose leaf's only read ([VISUAL_EDITOR.md](VISUAL_EDITOR.md), `readLeaf`), and the leaf holds no codec of its own to stand in for it. `reader.getContentAt(addr, path)` is that read at depth — an element of an `array<richtext>`, a content property of an `object`, a variant's content cell, a leaf under both — and it is the only read every by-value prose leaf has, so neither a row nor a subform cell lowers a stored string itself. The write has no such door on purpose: `Addr` gains no element axis, since `storeField` / `isFill` / `applyChange` could not answer one, which is why an array element is committed by value with its whole array. The editor drives neither ingestion verb (`quill.parse` / `quill.conform`): it is handed a `Document` and edits it, so which door built one is the host's business and a transport-door document opens here unconformed. The model carries no card `$id` and no `cardIndexById`: the editor's durable card handle is its own session key.

**The content vocabularies are closed.** `ContentLine.kind`, `ContentContainer.container`, a mark `type` and an island `type` each admit their built-ins and nothing else: a name outside one is refused wherever content is decoded, and a stored row holding one stops opening. So a bare discriminant check narrows — `line.kind === 'heading'` reaches `line.attrs.level` with no guard to call — and the codec carries no inert carrier for a construct it cannot hold ([CODEC.md](CODEC.md) §Vocabularies). **Every member spells its payload in `attrs`**, so the narrowing lands on the payload rather than on whether there is one, and the envelope keys (`kind`/`type`/`container`, `containers`, `continues`, `start`/`end`, `instance`) are the only siblings.

Content types (`Content` and its parts) and their ProseMirror mapping are the editor's own work: [CODEC.md](CODEC.md), not here.

**Moving the pin reads upstream.** The break record for a version step is quillmark `docs/migrations/`, one guide per step; a jump across several reads the span guide `0.92-to-0.102.md`, which leads with the breaks a type checker does not report, which are what follows. The `insertCard(card, at?)` reorder is reported only where the call site is typed, and throws on first use rather than corrupting a document. The 0.104.0 index respelling is reported nowhere at all: `FieldRegion.field` and `ContentHit.field` are still `string`, so a prefix match or a trailing-digit read written against the dotted form compiles and silently stops matching — which is why the two places this package read one carry a case each (`boxesForField`, `elementAddrForFieldPath`). The 0.105.0 break lands on the schema rather than on a signature, beside one rename a type checker does report (`FieldSource`'s `zero` rung is `blank`). **An enum's accepted domain is `values ∪ blank`**, the blank being the field's spelling of explicitly-nothing, engine-supplied for every enum and declarable in `values:` by none — which is a load error, and the shape the reference quill declared until that pin; `validate` gains its unauthored trigger under the obligation code, so a document that is merely incomplete stops validating clean. The 0.106.0 break is the 0.104.0 respelling's twin and is reported the same nowhere: **a region address may name a property of a declared container**, so a plate reading `#data.contact.email` regions as `main.contact.email` where it regioned as `main.contact`, and `fieldAt` answers the same. Both places this package reads one already hold it — `boxesForField` matches on a path boundary, and `elementAddrForFieldPath` takes an index terminal only, so a property path declines there and lands its field through `nearestAddrForFieldPath`. The 0.107.0 break is the third in that line and reads the same way: **a read of a typed table's row cell regions on the cell**, `main.refs[0].org` where it regioned as `main.refs`, and beside it a whole-array read and a single-assignment `let` alias each mint an address that minted none — so a container now carries a region of its own *and* its elements'. That pairing is what this package moved for: `boxesForField`'s descendant rung was a fallback and is now a union, an array's own region being the ink the plate composes around its rows rather than the rows themselves ([PREVIEW.md](PREVIEW.md)). `fieldAt` may name that container where `positionAt` names the element inside it; the click ladder reads `positionAt` first, so what a click lands on is unchanged. The 0.108.0 step retires **`must_fill:`**, which is the one break in this span a type checker reports — `QuillFieldSchema` loses the key — and it takes an axis with it: obligation is a reading of `default:`, never a declaration beside one, so the required `*` is `default:`'s absence alone and no field ghosts a default under a `*` again. Two breaks ride behind it that nothing reports. **A typed dictionary declares no `default:`/`example:`** — one is a load error naming the properties that hold it — so obligation is exempt at that rung, or every subform draws a `*` (`obliged`, `structure.ts`); the reference quill's `contact` drops the `{}` it declared, and its cells are reached whether or not the container is authored. **A container's rung is the strongest its cells contribute**: `authored` where the document wrote any of it, else `default` where a cell below resolved to one. `ghostDefault` keys on that rung and `stringifyGhost` declines an object at any of them, so what moves is the provenance a host reads, not what the surface draws. The gate closes another — `init` hands out what it instantiates, so a missing await has no name to call. The 0.108.1 step breaks nothing: **`getContentAt` walks a variant's key**, where it walked `items` and `properties` alone and answered `edit::field_not_content` naming the `enum` for a cell the same config declares `plaintext` — so a content cell under `variants:` has a read at its codec, and the surface mounts a leaf over it. The 0.108.2 step breaks nothing and lands on emit: **an empty mapping emits `key: {}` at every depth**, where it dropped its own key and left the parent a bare `$ext:` that read back as null and failed the next parse — the save a dismissed tips card used to hand a host. The 0.108.3 step breaks nothing: **a run that is one bare Typst line marker is escaped**, `/` above all, which reached the compile as a term list whose colon is missing and failed it — so a paragraph holding the `/` that opens the slash menu renders, where the preview drew `expected colon` on that keystroke and cleared on the next. The 0.109.0 step left that line at 0.110.0, where a type checker reports it: **two adjacent containers of one shape are two**, and `ContentContainer.instance` is what tells one from the other where contiguity plus an equal path reads them as one. The seam spells the field on every lane typed `Content`, so the read type requires it and `ContentContainerInput` is deleted — a hand-built container literal that omits it stops compiling, and `LineOp.setContainers` takes the one shape. What no checker reaches is a `0` stamped on every run, which is that same weld written a second way: two quotes in a row come back one two-paragraph quote, and an ordinal reset stands for no list boundary now that a run's `ordinal`s canonicalize gapless from 0. Adjacency is the rule, not the type, and both halves are the codec's — the projection alternates each container's `instance` against the sibling before it, the fold keys on what it reads ([CODEC.md](CODEC.md) §Decode). The 0.110.0 step is another in that line and lands on the diagnostic feed rather than on a signature: **`validate` refuses only what the render floor refuses**, each document value conformed at the render leniency before it is judged, and conformed per node so one refused element no longer mistypes its siblings. A value the floor adopts — a bare scalar for an `array`, `"3"` for an `integer` — raises nothing where it raised `validation::type_mismatch`, and a bare scalar the floor stringifies into an `enum` field is domain-checked on that string, so a spelling outside `values:` raises `validation::enum_violation` where it was silent. A fatal `validation::*` therefore means the document does not render. The three codes the validation lane words are unchanged ([VISUAL_EDITOR.md](VISUAL_EDITOR.md)); what moves is which of them arrive. Nothing else in either release reaches this tier: `Normalized` is a Rust precondition, the op wire loses encoders in a direction only Rust ever emitted, storage keeps its omitted zero so stored blobs re-encode byte for byte, and a container inside a list item stops ending its list on the Typst side of the seam. The 0.111.0 step is a fix release, and its one break that reaches this tier is reported nowhere: **the schema echo keeps `inline: true` on a `plaintext` field**, where it served the flag for richtext alone. A quill declaring the pair mounts those leaves as the one-line leaves they asked to be, and `packable` takes the `ui.compact` beside them, so a field that spanned its row packs into a cell where its neighbours pack too; both fixtures declare it. Every other break in that release lands on a surface this tier does not read. What the release adds is the one this tier moved for: **`mapMarks(content, bundle)` answers where a bundle's text-moving channels leave a field's marks**, so the mark diff subtracts against the store's own rebase instead of reproducing its assoc rule ([CODEC.md](CODEC.md) §Encode). The 0.112.0 step closes the split that made the set open in two spellings: **a payload rides `attrs` at every member**, where a built-in put it in named siblings and an unknown in one opaque bag, so which spelling a document used depended on whether the build that wrote it knew the name and promoting a name was an encoding change. `Heading{level}`, `Code{lang}`, `Link{url}`, `Anchor{id}` and a `list_item`'s `ordered`/`start`/`ordinal` all read one level down. A type checker reports the read side, the narrowing types moving with the guards, and reports nothing on the write side that matters most: `MarkOp` still declares the siblings while the wire refuses them as a `legacy mark payload`, so the codec's `as MarkOp` casts carry the op wire rather than merely satisfying a spread ([CODEC.md](CODEC.md) §Encode). The rest of the authored lane throws the same way — `overwrite`, `install`, `CardInput.body` — while stored documents need no migration, the decoder reading the sibling spelling wherever the bag is absent. What the seam gains in exchange is a tie-break both sides compute alike, the canonical mark order being the `(type, attrs)` pair the wire carries, which is `markKey`'s whole rule now that no arm needs a case of its own. Canonical bytes move with it, so a hash over the content or over `exportMarkdown` recomputes once; this tier holds none. Beside it `fieldAt`/`positionAt` take a pointer tolerance in PDF points and answer with the nearest ink inside it, which is what makes a click into the leading between two lines land: the argument is optional and defaults to the exact behaviour, and the click bridge states one ([PREVIEW.md](PREVIEW.md)). The 0.113.0 step closes what 0.112.0's one spelling was the groundwork for: **the five content vocabularies close**, a line `kind`, a container, a mark `type`, an island `type` and an island's `loss` each admitting their built-ins and nothing else. A type checker reports the read side — the residual arm leaves each union, so a discriminant check narrows on its own and the eleven content guards are deleted — and reports the write side too, a literal outside a set being a type error. What it cannot report is the tier this step deletes: an unknown had to survive an edit, so each open set carried an inert PM carrier, and every one of them — the `unknown` mark, the paragraph's `unknown` attribute, the `unknown_container` node, an island type off the DOM — is gone, the clipboard forms included ([CODEC.md](CODEC.md) §Vocabularies). Beside it the canonical form loses its second spelling: **a zero `Container.instance` is omitted**, where a read spelled it on every container, so the projection omits one too or `lineMetaEqual` reads every list edit as a metadata change. A second break nothing reports lands on the line model: **a heading takes no continuation**, the store clearing a `continues` after a block of one line, so the PM schema declares `hard_break` out of a heading and a stray `\n` there becomes the space its own DOM was already drawing. The rest is verbs moving or leaving: `quill.resolve(doc)` is `reader.resolve()`, `setCardKind` is an `insertCard` plus a `removeCard` at the index, `makeCard` is a `CardInput` literal, the three `$ext` namespace verbs are a spread over the whole-map three, `toJson` / `fromJson` / `loadJson` name their lane as `toStored` / `fromStored` / `loadStored`, and `Diagnostic.sourceChain` and `RenderResult.renderTimeMs` go. **Canvas stops being a capability**: every backend paints, so `Engine.supportsCanvas`, `LiveSession.supportsCanvas` and a `BackendDescriptor`'s `canvas` key are deleted and a counted page is the whole contract — which is why the preview's `unsupported` message state goes with them ([PREVIEW.md](PREVIEW.md)). Two breaks reach the fixtures rather than the code: the Typst `form-field` helper keeps `text` and `signature`, so a checkbox widget is an `acroform` quill's or the plate's own glyph, and `.quillignore` is not read, so a bundle carrying one ships it as an ordinary file. A card-yaml parse failure locates on `Diagnostic.location` in the document's own coordinates and `args` drops its `line`. The 0.114.0 step breaks nothing here and is the first in this span whose whole content is surface this tier draws: **`type: matrix`**, a closed vocabulary someone ticks, with `QuillFieldSchema.members: QuillMatrixGroup[]` as the roster, which `controlKind` answers `'matrix'` for and the matrix control draws ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §"The matrix"); **`ui.layout: "table"`**, a control request on an `array<object>`, granted where every cell of the row is short and declined otherwise; **`max:`** on an array, warned past as `validation::cardinality` at the field's own path and never gating render, which the add chip stops at; and **`formatDiagnostic`**, the engine's own printer, which is the other lane from the one this tier words itself by `code` + `args` ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §Diagnostics) and the one of the four this tier does not call. Two facts about the new keys are worth stating once, both of them cheap to read the other way round. **`layout` sits on the array field's own `ui`**, describing the array, where `title` sits on `items.ui`, describing a row; the loader refuses `layout` anywhere but an `array` whose `items` is an `object` (`quill::invalid_ui`). **The `{held, …columns}` object a matrix member desugars to is derived at parse and not serialized**, so `members` is the roster alone and a consumer composing the member's shape composes it from `members` × `properties`; key presence is the tick, so a mapping naming no `held` is held, and the typed writer rests every member at the object form on any write to the field. The boundary walks a matrix's member and its columns in `getContentAt` as it walks `properties`, so a content column reads at its codec at `[id, column]`. One break reaches the fixtures rather than the code: **a card kind declaring `body.enabled: false` warns** (`quill::bodiless_card_kind`), which the reference quill's `signoff` does on purpose — it is the kind that renders no body leaf, and the warning is the loader seeing a proxy for a fact `Quill.yaml` does not state. The 0.115.0 step cuts, and its break that matters most here is reported nowhere: **a matrix member spelled as a mapping naming no `held` is unheld**, the tick resolving to its `default:` as every absent cell does, where key presence ticked it — so `matrixHeld` reads `{note: x}` as unticked with the note retained, the member write already naming `held` explicitly. The rest a type checker reports. **An island stores its value, not its provenance**: `ContentIsland.loss` and `ContentLossClass` are gone, the island node drops its `loss` attribute and the clipboard its `data-qm-island-loss`, so the closed vocabularies are four. **A block island's line is a `para`**: `ContentLineKind` loses its `island` arm, decode reads a block off the island backing a lone slot (`isBlockIsland`), and encode lands a table in two channels, the `setKind` gone ([CODEC.md](CODEC.md) §Islands). **A matrix roster is one flat mapping**: `QuillMatrixGroup` is deleted and `QuillFieldSchema.members` is `Record<string, string>`, so the control draws one list ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §"The matrix"). Two breaks reach the fixtures: the reference quill's roster flattens, and **a `ui.layout: table` column that is not a leaf is `quill::table_column_not_flat` at load**, so `appendices` stops asking for a grid it was always declined. What the step adds is reported nowhere either: **a typed dictionary's property may open a variant world** (`header.classification`), which the address walk steps as it steps a card-level variant and the object subform draws as a card-level field draws it ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §"Enum variants"). The 0.116.0 step's break that matters most here is reported nowhere: **a seed answers nothing**, `seedDocument` and `seedCard` committing no `example:` and no `body.example`, so a fresh document is every field absent and every body empty, and starter content lives in a template document's own body; the suite and the playground open `fixtures/templates/<quill>.md` through `quill.parse` for the filled document they drive. **A label is a top-level `title`**, on a field and on a card kind, where it sat under `ui`: `ui.title` and a `{field}` token in a `title` fail the load, and an array's `items` takes none, so a card header is the kind's literal where it declares one and the instance's first short text cell where it does not, the cell a collapsed row reads. **An optional cell spells its type `t?`**, and that too is reported nowhere: `QuillFieldSchema.type` gains a suffixed arm, so a comparison against `'plaintext'` compiles and misses a `plaintext?` cell, and a switch over it lands in its `default` arm. The last row is the odd one: no code in this package calls it. The surfaces mount over live handles, so a host that stores text owns getting one open and reading it back out, and those verbs are load-bearing for an integration while appearing in no prop and no signature here; what a host does with them is [HOSTING.md](HOSTING.md).

**A ghost is not always a `default:`.** `resolve`'s `FieldSource` rung is the boundary's, and a `default`-sourced row is a promise about the render: this is what prints if you write nothing. The editor ghosts that row verbatim for every control, and for a body that has one. An optional cell's unanswered render is `none`, which it ghosts as `strings.optionalGhost` words it. Everything else a ghost says is an invitation ([VISUAL_EDITOR.md](VISUAL_EDITOR.md)): a focused, unset free-text field's `example:`, and on a body with no `default:` (the case for every kind the reference quill declares) its kind's `body.example`, else the consumer's `bodyPlaceholder` wording, else the built-in `Write…`. All of them render at the same rung, and none is ever written back, so on screen they are one thing; they are not one thing here. Only the `default:` came from the boundary as a value, and a fallback must never be read back as one: nothing derives a schema value from what a leaf displays.

Two neighbouring surfaces the editor consumes but never drives: it selects no `OutputFormat` (Preview paints a page; it emits no artifact) and it routes diagnostics by `path`, never by a backend's error `code`.

**Every type nests at every depth** (0.107.0): a property or an element carries whatever a card-level field carries, itself included, and `quill::nested_object_not_supported` / `quill::nested_array_not_supported` are gone — a consumer matching either code will never see it again. The editor's controls compose by nesting rather than by position, so a deeper schema draws through the same controls at the next rung ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §"Structure mirrors the schema"); what no surface holds is a floor on depth, the reference quill declaring an `array<object<array<object>>>` and a record list inside a variant cell.

**`QuillFieldSchema.variants` rests an enum as a container** — a card-level field or a typed dictionary's property — `{value: <member>, …that member's fields}`, so the discriminant is one cell of it and the per-member fields are siblings. It is the one schema key that changes a field's resting shape, and the editor reads it: the control is the discriminant's select over the cells the live member declares ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §"Enum variants").

## Stability seams

At the 0.116.0 target the whole table is stable API. `ContentLineKind` and `ContentMarkKind` are on the public entry point, so the codec builds its `setKind` and mark ops typed (`encode.ts`, `kindOp` and `diffMarks`). The island type rides a PM node attribute, and the codec reads it off the entry (`ContentIsland['type']`, `islands.ts`) rather than restating the union, which would be a local copy of a closed set, the one duplicate that goes stale silently.

One obligation the closure carries here:

- **Adding a construct is a storage-version event upstream, and a compile error here.** A vocabulary has no residual arm to route a stranger through, so a name upstream promotes has to reach this tier as a refusal the checker makes rather than a fall-through some arm absorbs. Nothing here restates a set as a literal check: the four places that name one name it against the boundary's own union — an exhaustive `switch` closed by a `never` (`decode.ts` §`makeLeaf`, `marks.ts` §`pmMarkFromContent`), a `satisfies` on the container left after the list (`decode.ts` §`groupBlocks`), and a `Record` keyed by the union for the island `type`, which the DOM reader admits and the decode reads a block off (`islands.ts`). A member added upstream is a missing case, a missing key or a widened `satisfies`, in that order.

Two shapes the editor reads straight off the boundary, with no local duplicate:

- **`ContentIsland.props`**: the union pins `TableProps` for `table` and `ImageProps` for `image` (`TableCell` the cell shape), and the type is closed, so a discriminant check narrows the payload. The codec needs no hand-rolled `IslandTable*` / `IslandImage*` shapes or guards ([CODEC.md](CODEC.md) §Islands). A `props` still crosses the DOM as opaque JSON, which is where the codec's own shape read stands (`tablePropsOfNode`).
- **`QuillCardUi.groups`**: a `Record<string, QuillGroupUi>` group registry (key order = declaration order, `title` an optional label override). The editor reads group order and labels off it directly, uncast ([VISUAL_EDITOR.md](VISUAL_EDITOR.md) §Structure).

Field addresses are one canonical `DocPath` across the boundary: `Diagnostic.path`, `ContentHit.field`, and `FieldRegion.field` all speak `main.<field>` / `main.body` / `cards.<kind>[<i>].<field>`, cards keyed by **absolute document index** (no per-kind ordinal). An array element is bracketed on every one of them (`main.keywords[0]`), so a diagnostic path and a geometry address for one place are the same string and join on equality; a nested key stays dotted. The editor routes on `parseDocPath` and builds with `formatDocPath` rather than a hand-rolled string grammar; diagnostics routing is confirmed against the real grammar, not best-effort.

The session/paint surface (`Engine.open`, `LiveSession`, `PageSize`, `ChangeSet`) is stable at the pinned 0.116.0 and the editor's Preview is its first production consumer: the editor pins the version and rides it.

## What the editor owns at this boundary

The substrate is quillmark's; two thin slices at the seam are the editor's, and they live in their surface docs, not here:

- **Handle lifecycle**: the package's own `init` (`/core`), which awaits the artifact's gate, hands the surface straight back, and latches it for the verbs here that cannot await one (the `DocPath` formatter on the public API, the codec inside a ProseMirror transaction); who holds the `Quill` and `Document` handles across a session, and when they are freed, under the one-copy-per-process rule the runtime enforces (`check:deps`). The vanilla-TS core owns this ([ARCHITECTURE.md](ARCHITECTURE.md) §Core vs chrome). The latch is the one place the package restates a precondition the gate made structural: it throws naming the fix rather than reading `undefined`.
- **Diagnostics routing**: three producers (`quill.validate`, `LiveSession.warnings`, render errors via `FieldRegion.field`) merged, keyed to field addresses (canonical `DocPath` → the editor's stable-id keying, via `parseDocPath`), and de-duplicated with a settled precedence. Policy lives in [VISUAL_EDITOR.md](VISUAL_EDITOR.md) §Diagnostics; this ledger only names the producers it draws from.
